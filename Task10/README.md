# Laundry Services Animation

A simple Laundry Services webpage with a custom CSS animation.

## Animation

The image has two animations running together:

- The image moves in a circular orbit.
- The image changes its shape at different points by squeezing and stretching.

The orbit animation rotates the image around the center continuously.

The squeeze animation changes the width and height of the image using different `scale()` values.
