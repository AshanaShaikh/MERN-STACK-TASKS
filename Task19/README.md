# Tutedude MERN Stack - Task 19

## Task: Laundry Service DOM Project

This project is a simple laundry service webpage created using HTML, CSS, and JavaScript. It demonstrates DOM manipulation by allowing users to add laundry services to a cart and automatically update the total amount.

## About the Project

The webpage contains a navigation bar, an Added Items section, available laundry services, and a booking form. Users can add different services to their cart and the selected services are displayed dynamically in the Added Items section.

The total amount is automatically calculated whenever a new service is added. Users can also enter their details and place an order using the Book Now button.

## Features

- Navigation bar with links and logout button
- Display of available laundry services
- Add items to the cart
- Skip services
- Dynamically display added items
- Automatic serial number generation
- Automatic total amount calculation
- Booking form for customer details
- Order Successful message after booking
- DOM manipulation using JavaScript
