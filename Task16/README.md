
# Task 16 - Student Records

## Task Description

This project displays student records in cards using HTML, CSS, and JavaScript. It includes a search box that filters student records by name while the user types.

## Features

- Displays student names, marks, class, and address.
- Uses JavaScript objects to store student information.
- Uses the `map()` function to create student cards.
- Uses the `filter()` function to search by student name.
- Updates the results instantly as the search text changes.
- Displays a message when no matching students are found.
- Responsive layout for different screen sizes.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Open the Task16 folder in VS Code.
2. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
3. Open `index.html` in your browser.
4. Type a student's name in the search box to filter the records.
