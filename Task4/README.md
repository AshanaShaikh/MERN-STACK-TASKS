# Tutedude MERN Stack - Task 4

## Task: CSS Viewport Units, Box Sizing and Gradient

This task demonstrates the use of different CSS properties to control the size and appearance of elements on a webpage. The webpage contains an image and a button styled using CSS.

## About the Project

The project demonstrates how CSS can be used to control the webpage layout using viewport units such as `vw` and `vh`. The `overflow` property is used to prevent unwanted scrolling, while `box-sizing: border-box` is used for better control over element dimensions. A linear gradient is also applied to the button to improve its visual appearance.

## Concepts Used

### CSS Properties

- `vw` – Viewport width unit
- `vh` – Viewport height unit
- `overflow: hidden` – Prevents page scrolling
- `box-sizing: border-box` – Includes padding and border within the element's dimensions
- `linear-gradient()` – Creates a gradient background
- `font-size` – Controls text size
- `font-family` – Defines the font
- `font-weight` – Makes the button text bold

## Features

- Displays an image on the webpage.
- Includes a Refresh button.
- Uses viewport width and height units.
- Prevents unwanted scrolling.
- Uses `border-box` sizing.
- Applies a blue-to-purple gradient to the button.
- Styles the button with bold text and a larger font size.
