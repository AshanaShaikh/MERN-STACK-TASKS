# Laundry Services Hamburger Menu

A responsive Laundry Services webpage with a mobile hamburger menu.

## Features

- Responsive layout
- Desktop navigation menu
- Mobile hamburger menu
- Menu opens from the right side
- Close button
- Background overlay
- Responsive for mobile and tablet screens

## Files

- index.html
- style.css
- script.js

## How to Run

Download or clone the project.

Open the project folder and run the `index.html` file in a browser.

## Technologies Used

- HTML
- CSS
- JavaScript
- Flexbox
