
# Task 17 - JavaScript Promise-based Division

## Objective

Create a JavaScript function that performs division using Promises and handles division by zero.

## Technologies Used

- HTML
- JavaScript

## Features

- Uses an arrow function to perform division.
- Returns a Promise from the function.
- Resolves the Promise with the division result.
- Rejects the Promise if the divisor is zero.
- Handles errors using catch().
- Tests five different input cases.

## How to Run

1. Open the Task17 folder in VS Code.
2. Open index.html in a browser.
3. Press F12 to open Developer Tools.
4. Select the Console tab to view the results.

## Sample Output

Dividing 10 by 2...
Result: 5

Dividing 20 by 4...
Result: 5

Dividing 15 by 3...
Result: 5

Dividing 7 by 2...
Result: 3.5

Dividing 10 by 0...
Error: Division by zero is not allowed.
