# Task 18 - Interactive Color Boxes

## Objective

To create an interactive web page using HTML, CSS, and JavaScript that allows users to change a greeting message and the background colors of boxes through user interactions.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Displays a greeting message with the heading "Hello".
- Provides four color boxes: Red, Blue, Green, and Yellow.
- Allows users to enter their name in an input field.
- Changes the greeting message to "Hello, [Name]" when the Greet Me button is clicked.
- Changes a box's background to its corresponding color when clicked.
- Uses JavaScript DOM manipulation and event listeners to handle interactions.
- Includes a responsive layout for mobile devices.

## Project Structure

```text
Task18/
├── index.html

```

## How to Run

1. Download or clone the repository.
2. Open the `Task18` folder.
3. Open `index.html` in any web browser.
4. Enter your name and click the **Greet Me** button.
5. Click any color box to change its background color.

- Event listeners and click events
