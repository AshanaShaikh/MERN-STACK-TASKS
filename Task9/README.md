# Laundry Services

A responsive landing page for a laundry service website.

## Task

Create a Laundry Services landing page and add a hover effect to the "Book a service today!" button.

When the user hovers over the button, the button increases in size.

## Features

- Responsive layout
- Navigation bar
- Laundry service landing page
- Call to action button
- Button hover animation
- Mobile and tablet support

## Files

- index.html
- style.css

## Technologies Used

- HTML
- CSS
- Flexbox

## How to Run

Open the project folder and run the index.html file in a browser.
