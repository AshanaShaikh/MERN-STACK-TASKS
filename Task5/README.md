Laundry Services Landing Page

Task

This project is a simple laundry service landing page created using HTML and CSS. It is designed based on the provided reference layout.

About the Project

The webpage presents a laundry service with a navigation bar, a hero section, a short introduction, a booking button, and a laundry-themed image.

Features

Navigation bar with logo and links

Username button

Hero section with main heading

Highlighted "Laundry Services!" text

Short service description

Book a service button

Laundry image section

Responsive layout for smaller screens

Technologies Used

HTML5

CSS3

Responsive design

Media queries

Border radius

Custom colors

Spacing and typography
