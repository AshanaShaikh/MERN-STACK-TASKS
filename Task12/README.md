# Task 12 - JavaScript Compound Interest

## Objective

The objective of this task is to create a JavaScript program that calculates compound interest using predefined values.

## Formula

A = P(1 + r/n)^(nt)

Where:

- A = Amount
- P = Principal
- r = Rate of interest
- n = Number of times interest is compounded per year
- t = Time in years

## Values Used

- Principal = ₹50,000
- Rate of Interest = 5%
- Compounding = 1 time per year
- Time = 3 years

## Technologies Used

- HTML
- JavaScript

## Output

The calculated compound interest is displayed in the browser console using console.log().

## How to Run

1. Open the project folder.
2. Open index.html in a browser.
3. Open the browser console using F12.
4. Check the calculated compound interest in the Console.
