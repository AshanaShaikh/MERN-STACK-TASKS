# Task 15 - Array Operations

## Task Description

This task demonstrates JavaScript functions that perform different operations on an array.

The program performs the following operations:

- Finds the maximum number in the array.
- Calculates the sum of all elements.
- Counts the number of odd numbers.
- Displays the results using `console.log()`.
