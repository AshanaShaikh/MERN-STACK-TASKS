# Tutedude MERN Stack - Task 3

## Task: HTML Elements and CSS Selectors

This task demonstrates the use of different HTML elements along with CSS selectors to style a webpage. It includes the use of element selectors, class selectors, ID selectors, pseudo-classes, and inline elements such as `span`.

## About the Project

The webpage contains different heading tags, paragraphs, links, unordered lists, and ordered lists. CSS is used to apply different colors, backgrounds, font styles, and sizes to specific elements.

## Concepts Used

### HTML
- Heading tags (`h1`, `h2`, `h3`)
- Paragraph tag (`p`)
- Unordered list (`ul`)
- Ordered list (`ol`)
- List items (`li`)
- Anchor tag (`a`)
- `span` element
- Classes and IDs

### CSS Selectors
- Element selector
- Class selector (`.`)
- ID selector (`#`)
- Descendant selector
- `:nth-child()` pseudo-class

## CSS Styling Implemented

- The webpage background is set to **blanched almond**.
- Heading elements inside the `.head` class are styled with **dark blue** text.
- The `#bglime` ID applies a **lime background** to the h2 heading.
- The word **"head"** is highlighted in **red** using a class.
- Paragraphs are styled with **italic** text and **orange** color.
- The paragraph with the `para` ID is displayed in **green**.
- The word **"paragraph"** is displayed in **black** with a larger font size.
- Links have a **yellow background**.
- Specific list items in the ordered list are styled using the `:nth-child()` selector.
